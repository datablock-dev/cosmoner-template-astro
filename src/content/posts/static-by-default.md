---
title: Static by default
description: Why this site is built once and served as files.
date: 2026-10-22
---

Astro renders every page to HTML at build time. The result is a folder of
files that can be served from anywhere, quickly and cheaply, with nothing to
patch or scale.

When you need something dynamic, add a client-side component, or call an API
you host alongside the site.
